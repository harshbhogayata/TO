# Frontend — Development & Deployment Guide

This document explains how to run, develop, test, and deploy the TalentOrbit frontend located in `src/`.

Tech stack
- React + Vite
- Zustand for state management
- Zod for schema validation
- dompurify for sanitizing HTML
- @axe-core/react for accessibility auditing
- Sentry for error tracking
