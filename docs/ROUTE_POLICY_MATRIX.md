# Route And Policy Matrix

Source of truth:
- Frontend routes: `src/App.jsx`
- Backend entrypoint: `backend/talentorbit/urls.py`
- Per-domain API routing under `backend/*/urls.py`

This matrix is the canonical launch-readiness reference for actor access, sensitive data, dependencies, guardrails, and expected failure modes. It intentionally favors live route groups over older generated audit notes.

Launch-critical scenarios to keep green:
- Public registration can parse a resume without authentication and without persisting the upload.
- Authenticated resume parsing returns the same response contract for traditional and AI-backed endpoints.
- Talent search stays denied for TALENT users and allowed for COMPANY or ADMIN users.
- Webhook creation, update, test pings, and async deliveries all reject localhost, metadata, and private-network targets.
- Checkout, portal, referral, and Stripe webhook flows remain idempotent under retries.
- Runtime checks run from the current Python environment instead of the checked-in virtualenv.
