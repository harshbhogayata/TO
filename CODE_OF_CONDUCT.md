# Contributor Covenant Code of Conduct

We expect contributors to follow a Code of Conduct that ensures a welcoming and respectful community. This project uses the Contributor Covenant v2.0.

Key points:
- Be respectful and civil.
- Do not harass or discriminate.
- Report violations to the maintainers (infra@talentorbit.com).

For the full policy, adopt the Contributor Covenant text at https://www.contributor-covenant.org/version/2/0/code_of_conduct/.
